## Objectif

Le champ Document permet de sélectionner un fichier de document dans un dossier de fichiers.

## Création du champ

Les paramètres communs des champs sont décrits dans un article séparé.

* **Titre** Le titre est visible et utilisé dans la liste des champs.
* **Étiquette** C'est ce qui est affiché dans le résultat. Si elle est laissée vide, elle est définie à partir du contenu du champ Titre, mais peut être modifiée.

![création du champ document](../../../en/images/fields/adding-custom-fields-document-field/01-fields-document-edit.png)

**Remarque :** Dans cet exemple, l'inclusion du type de champ dans le Titre sert uniquement à des fins de démonstration. Omettez-le dans les titres de vos propres champs.

## Saisie des données

À l'utilisation, le champ Document est simple. Vous sélectionnez le fichier de document requis à l'aide d'un sélecteur de médias.

La capture d'écran suivante montre un fichier audio sélectionné :

![saisie des données du champ document](../../../en/images/fields/adding-custom-fields-document-field/02-fields-document-data-entry.png)

Les champs apparaissent dans un article uniquement s'ils sont renseignés dans le formulaire de saisie des données de l'article.

## Affichage des données

La capture d'écran suivante du site montre le champ affiché dans un article. L'option *Affichage automatique* est responsable de la position du champ et votre template est responsable de la conception du champ.
