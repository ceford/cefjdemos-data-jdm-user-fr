## Objectif

Le champ Vidéo permet de sélectionner un fichier vidéo dans un dossier de médias.
Il permet également de sélectionner une image à utiliser comme affiche pour la vidéo,
généralement la première image de la vidéo.

## Création du champ

Les paramètres communs des champs sont décrits dans un article séparé.

* **Titre** Le titre est visible et utilisé dans la liste des champs.
* **Étiquette** C’est ce qui est affiché dans le résultat. Si elle est laissée vide, elle est définie
à partir du contenu du champ Titre, mais peut être modifiée.

![création du champ vidéo](../../../en/images/fields/adding-custom-fields-video-field/01-fields-video-edit.png)

**Remarque :** Dans cet exemple, l’inclusion du type de champ dans le Titre sert uniquement à
des fins de démonstration. Ne l’incluez pas dans les titres de vos propres champs.

## Saisie des données

À l’utilisation, le champ Vidéo est simple. Vous sélectionnez le fichier vidéo requis à l’aide d’un
sélecteur de médias.

La capture d’écran suivante montre un fichier audio sélectionné :

![saisie des données du champ vidéo](../../../en/images/fields/adding-custom-fields-video-field/02-fields-video-data-entry.png)

Les champs apparaissent uniquement dans un article s’ils sont renseignés dans le formulaire de saisie des données de l’article.

## Affichage des données

La capture d’écran suivante du site montre le champ affiché dans un article. L’option *Affichage automatique*
est responsable de la position du champ et votre modèle est responsable de la conception du champ.
